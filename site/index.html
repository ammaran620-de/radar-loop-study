METHODS / HONEST BOUNDARIES

Methodology and scope

This console replays final offline estimates and a full-segment fused map from recorded public-data experiments. Earlier frames can include corrections from later loop constraints; playback is not an online-estimator simulation. It is not a live sensor feed or an official agency system.

The pretrained RadarLoc network belongs to its authors. Original integration and experiments were prepared with AI assistance. Boreas observations are CC BY 4.0; upstream model code is MIT licensed.

Development settings were frozen before the separate-session test. The pose graph uses real consecutive radar registrations; no noisy ground-truth trajectory is manufactured.

The ground-truth-initialized oracle is a separated diagnostic only. It never supplies inference decisions or graph factors.
